# Notebook Review Wall

## Build
- Replace the placeholder home page with a dedicated patient-reviews experience.
- Present every unique review found on the supplied website as a torn, lined notebook-paper card.
- Add five-star ratings, reviewer details, dates, and a Google-style multicolor mark to each card.
- Arrange cards in a continuously looping horizontal strip, with pause-on-hover and touch-friendly scrolling.
- Scatter restrained hand-drawn hearts, sparkles, arrows, and underlines across the section for an organic scrapbook feel.
- Match the supplied off-white paper, soft gray canvas, typewriter typography, imperfect rotations, punched holes, and layered shadows.
- Make the page responsive and add reduced-motion behavior.
